# Support

[中文](SUPPORT_ZH.md)

Use the following channel according to the type of request:

- Reproducible example, documentation, or repository problem:
  [open a GitHub issue](https://github.com/waveshareteam/ESP32-P4-WIFI6-Touch-LCD-4.3/issues/new/choose).
- Product selection, order, warranty, or private customer information:
  [contact Waveshare support](https://www.waveshare.com/contact_us).
- Connector orientation, flashing, and product operation: consult the
  [official product documentation](https://docs.waveshare.com/ESP32-P4-WIFI6-Touch-LCD-4.3)
  first.

For a technical issue, include the product and board revision, example path,
ESP-IDF version, exact reproduction steps, expected and actual results, and a
short relevant log. Remove Wi-Fi credentials, tokens, local paths, device serial
numbers, and unrelated output before posting.

This public repository does not currently advertise a verified private
vulnerability-reporting endpoint. Do not publish exploit details or secrets in
an issue. Contact Waveshare support first and request an appropriate private
channel for sensitive security information.

Actions performs compile validation only. Hardware behavior, factory firmware,
flashing offsets, and release packages require separate product or maintainer
confirmation.
